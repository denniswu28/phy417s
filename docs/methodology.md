# Methodology

This document describes what the software does, stage by stage. It describes a
**synthetic demonstration**. Nothing here is a scientific method for analysing a
real observation, and nothing here validates any historical implementation.

Claim IDs in this document refer to [`claim-evidence.md`](claim-evidence.md).

## Boundary, stated once and applied everywhere

- Every datum is synthetic and generated by this package (`GS-SYN-001`).
- No measured observation is shipped, read, or reproduced.
- No rotation curve, galactic-structure quantity, calibration accuracy,
  uncertainty, or detection is produced or claimed (`GS-ROTATION-001`,
  `GS-GALSTRUCT-001`, `GS-CALACC-001`, `GS-UNCERT-001`, `GS-DETECT-001`).
- The Doppler convention and rest frequency below are a **synthetic-demonstration
  convention only** (`GS-VEL-001`). They do not answer owner-brief question 13,
  do not select the historically correct scale or formula for the measured files
  this repository does not ship, and do not validate the legacy implementation
  described in the accepted private audit (`GS-UNITS-001`).

## Stage 1 — Configuration

`galaxy_structure.config` parses and validates a JSON configuration.

- Every key is required and every unknown key is an error, so an unsupported
  stage cannot be requested and no value can be silently defaulted.
- Ranges are checked: channel counts, strictly positive widths and frequencies,
  a non-negative noise scale, odd window widths, a frequency-compatible rest
  frequency unit, and a supported Doppler convention.
- `config/demo.json` is the documented copy of the built-in default. A test
  asserts the two never drift apart.
- `config_checksum` is the SHA-256 of the configuration's canonical JSON form and
  is recorded in every manifest and figure-provenance record.

## Stage 2 — Synthetic spectrum generation

`galaxy_structure.synthetic.generate_spectrum` builds

```text
amplitude(volts) = baseline + peak * exp(-0.5 * ((f - f_center) / width)^2) + noise
```

on a strictly increasing, uniform frequency grid.

The noise is drawn from `numpy.random.default_rng(seed)` (`GS-RNG-001`). The
same configuration and seed give identical arrays; a different seed changes the
noise and leaves the grid untouched.

The shape is chosen so the downstream stages have something to operate on. It is
**not** a simulation of an instrument, a receiver, a sky model, or an
observation, and it does not reproduce any measured file. The grid span and
channel count resemble the shape recorded for the historical files in the
accepted audit only so the schema exercise is realistic.

## Stage 3 — Schema and unit validation

`galaxy_structure.spectrum.Spectrum` is the two-column contract, and it is
validated on construction (`GS-VALID-001`):

| Rule | Rejected input |
| --- | --- |
| One-dimensional columns | An array of any other rank |
| Equal column lengths | Mismatched frequency/amplitude lengths |
| At least two channels | An empty or single-channel spectrum |
| All values finite | `NaN`, `+inf`, `-inf` in either column |
| Strictly positive frequency | Zero or negative frequency |
| Strictly increasing frequency | Descending or duplicated frequency — **sorted silently, never** |
| Uniform grid | Channel spacing varying by more than a relative `1e-9` |
| `synthetic` label | Any other label, including `measured` |

Stored arrays are defensive read-only copies, so a spectrum cannot be mutated
after construction and constructing one cannot freeze a caller's array.

On disk the format is two whitespace-separated columns with a comment header
declaring `Frequency, Hz` and `Amplitude, Volts` and a conspicuous `synthetic`
marker. Values are written with Python's shortest round-tripping float
representation, so a write/read cycle is exact and the bytes are stable.

## Stage 4 — Deterministic interference injection

`galaxy_structure.interference.inject_interference` adds each configured
narrow-band feature to the channel nearest its configured centre, across an odd
number of channels, and records every channel index it touched. Only amplitudes
change; the frequency axis is never modified. There is no randomness in this
stage at all.

## Stage 5 — Masking and cleaning

`galaxy_structure.interference.clean_interference`:

1. computes a running median over `window_channels` as a robust local baseline;
2. computes the residual, and a scatter estimate `1.4826 * median(|residual|)`;
3. flags a channel when its **positive** residual exceeds
   `threshold_sigma * scatter`;
4. replaces each flagged channel with its local median; and
5. returns the cleaned spectrum, the boolean mask, and the indices actually
   altered.

Guarantees, all under test (`GS-CLEAN-001`):

- every unmasked sample is copied through **bitwise unchanged**;
- every altered sample appears in the mask; and
- the full mask is written to `synthetic_interference_mask.csv`, listing each
  masked channel's index, frequency, original value, and replacement value.

Documented limitations of this strategy:

- A running median **follows** any feature occupying at least half of its
  window, so a feature that wide cannot be flagged. The demo configuration keeps
  every injected spike well below that limit, and a test asserts the limitation
  explicitly rather than hiding it.
- When the robust scatter estimate is exactly zero — a degenerate spectrum — the
  cleaner flags nothing and alters nothing, rather than treating ordinary
  curvature as interference.
- This is a **software** strategy demonstrated on synthetic interference that
  this package injected. It is **not** validated interference removal, and it
  makes no signal-preservation claim for any real observation.

## Stage 6 — Frequency-to-velocity conversion

`galaxy_structure.velocity` converts frequency to a velocity coordinate.

Both inputs are mandatory and explicit (`GS-VEL-001`):

- **rest frequency** — an Astropy `Quantity` with a frequency unit. A bare
  number is rejected. This is deliberate: the accepted audit records that the
  historical source carried two different rest-frequency scales for the same
  symbol (`GS-UNITS-001`), and a declared unit makes that class of error
  impossible.
- **Doppler convention** — one of `relativistic`, `radio`, `optical`. It is
  never inferred, and there is no default parameter value.

The documented default for this demo is Astropy's relativistic Doppler
equivalency (`GS-DOPPLER-001`) with the NIST recommended hydrogen hyperfine
frequency `1 420 405 751.768 Hz` (`GS-REST-001`) — an external reference value,
not a result of this project.

Verified behaviour: the rest frequency maps to exactly zero velocity under every
supported convention; a frequency → velocity → frequency round trip agrees to a
documented relative tolerance of `1e-12`; and declaring the rest frequency in
MHz rather than Hz gives identical results, because the unit carries the scale.

See [`units-and-frames.md`](units-and-frames.md) for the reference-frame
boundary.

## Stage 7 — Figures

`galaxy_structure.plotting` renders exactly two figures, from data it is handed;
it recomputes no physics. Each figure carries a conspicuous
`Synthetic demonstration` banner, a caption bound to a registered claim ID,
explicit axis units, and the reference-frame boundary.

Determinism: the non-interactive `Agg` backend, a fixed figure size, DPI, style
and font, a fixed plotting order, and removal of the PNG `Software` metadata
entry, so no library version, creation time, host name, user name, or path
reaches the bytes. Figures are committed as **PNG only** — never PDF or SVG,
both of which embed producer and creation metadata by default.

## Stage 8 — Manifest

`galaxy_structure.manifest` records, for one run: the configuration and its
checksum, the seed, the pinned package versions, the command **template**, the
reference-frame boundary, the boundary statements, and a SHA-256, byte count and
`synthetic` label for every artifact.

The manifest records **no absolute path, host name, user name, or timestamp**
(`GS-PATHS-001`), which is what makes two runs in different directories
byte-identical (`GS-DET-001`). `validate_manifest` re-reads the directory and
fails on a missing artifact, a changed checksum, or an unexpected extra file.
